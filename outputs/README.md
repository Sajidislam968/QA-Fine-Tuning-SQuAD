# Notebook Outputs

This directory stores results from the executed SQuAD question-answering notebook.

- Put plots and screenshots in `figures/`.
- Put the metric JSON, prediction CSVs, training history and final report in `tables/`.
- Only include files generated by your actual notebook run.

See [`../OUTPUTS_GUIDE.md`](../OUTPUTS_GUIDE.md) for the full output checklist and required filenames for README image rendering.
